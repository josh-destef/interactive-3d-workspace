## Review and finish — 2026-09-07 (later session)

Fixed, all verified in a real browser (Playwright, Chromium, served over
`http://localhost:8765`):

- **The lesson rendered no particles at all.** `spawn()` filled a pool slot but
  never set `alive = true`, so `update()` skipped every particle and the stage
  showed only the robot. Static checks and the old QA script could not see this
  because neither ran the lesson's own code.
- Split the simulation into `polished/labs/particle-cannon/js/particles.js`
  (pool, emission, integration, no DOM) with `js/main.js` holding the stage,
  rig, controls and beats. Both files are now written in the commented,
  readable style the other polished labs use, instead of 200-character lines.
- Rewrote `scripts/qa-particle-cannon-lab.mjs` to import the shipped
  `particles.js` (rewriting only the bare `three` specifier, the same trick
  `qa-particle-cannon.mjs` uses). It now covers births and the live count, rate
  integration, trajectory independence after an aim change, gravity, expiry,
  the pool ceiling, the spread cone, spark colour, and slider defaults matching
  the simulation defaults. Mutation-tested: removing `alive = true` fails it.
- **Sparks were invisible even once alive.** Vertex colours were written as
  sRGB numbers into a linear colour buffer, so the orange washed out to
  near-white on the pale stage. Colours now come from `THREE.Color` CSS values;
  size, alpha falloff and normal (not additive) blending were tuned against
  screenshots.
- Camera now frames a fixed sphere around the robot and the arc, fitted to
  whichever field of view angle is tighter, so portrait canvases frame the same
  action. Defaults changed to speed 6 / gravity 9 so the arc lands inside the
  shot. Added OrbitControls.
- **Mobile layout was broken**: a `margin-top: 465px` hack put the canvas under
  the lesson text and the absolutely positioned legend escaped the stage.
  Stylesheet rewritten (readable, tokenised) with a real stacked layout below
  760px; verified at 430x900 with no overflow.
- **The lesson was unreachable from the site.** Added the card to
  `polished/index.html` after Particles, with a new preview image
  `assets/lab-previews/particle-cannon.png` captured from the running lab.
- Applied the side grip pad fix the earlier session could not land: centres
  `(.440, ±.202, -.124)`, dimensions `(.145,.028,.100)`. The pads now stand
  22mm proud of the housing and are still seated in it; `qa-particle-cannon.mjs`
  asserts both and reports `gripProudOfHousing`. Asset rebuilt in Blender and
  the four `docs/qa/particle-cannon/*.png` renders regenerated and reviewed.
