The rhythm js/beats.js

Every beat is one idea, and every beat runs the same five stages. The runner enforces the two rules that are easy to break by hand: a demo never satisfies its own gate, and the caption does not change between Watch and Do.

  • Reset — chrome cleared, animations dropped, gates emptied, progress set.
  • Read — the idea, centered and still, waiting on the student. Nothing moves until they say go.
  • Watch — a demo drives the real control, dock locked, real cursor hidden.
  • Do — the same words stay put, the control unlocks, a gate watches.
  • Continue — appears the moment the gate passes, and never before.
const beats = createBeats({
    total: TOTAL_BEATS,
    copy:     COPY,        // idx -> { step, title, body, panel, cta }
    controls: CONTROLS,    // idx -> ['roughness']
    stage:    stageFor,    // (idx) => pose the scene
    demos:    { [BEAT.SIZE]: demoSize },
    gates:    { [BEAT.SIZE]: key => trackSpan('size', values.size) >= 45 },
});
beats.run(BEAT.INTRO);     // then beats.notify('size') on every change

Teaching the pointer js/mouseDiagram.js · js/demoCursor.js

“Right-click and drag” is three words a beginner has to translate into a hand movement. A picture of the mouse with the right button shaded is not. Drop one into a caption body with buildMouseDiagram('pan').

The demo cursor js/demoCursor.js

The pixel pointer that drives a Watch demo. Its press glow says which mouse button is down — and nothing else. Which button to hold is the one thing about a mouse a beginner cannot guess, so that is what the colour is spent on. Don’t recruit green for “a click rather than a drag”: a left-click and a left-drag are the same button, so they are the same colour.

idle
Travelling. No button down.
left button — orange
Orange. Dragging a slider, a gizmo arrow, or clicking anything at all.
right button — green
Green. A right-drag — panning the camera in Navigate + Transform.

Press Watch on the shell above to see it run: the cursor starts near the middle of the screen and travels to the control, because a pointer that simply appears in the bottom corner is a pointer nobody notices.
