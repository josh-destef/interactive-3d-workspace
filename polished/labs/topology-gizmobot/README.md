# Gizmobot Topology

Learners inspect Gizmobot's triangles and reduce detail until the character no longer reads clearly. `subject.js` loads the local topology/LOD variant; `lesson.js` and `meter.js` stage and assess it. Rebuild with `python scripts/build-topology-gizmobot.py`, run `node scripts/qa-topology-gizmobot.mjs`, and serve the lab.
