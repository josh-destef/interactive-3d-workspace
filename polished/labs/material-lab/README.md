# Material Lab

Learners control colour, roughness, metalness, lighting, and emissive glow, then match a generated target. `beats.js` stages the lesson, `subject.js` loads the material-specific Gizmobot export, and `match*.js` runs the challenge. The local GLB and semantic textures are intentional. Run `node scripts/qa-polished-curriculum.mjs` and serve the repository.
